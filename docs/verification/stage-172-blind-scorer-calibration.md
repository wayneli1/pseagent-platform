# 阶段 172：独立验收评分器语义校准

## 结论

独立百题评分器已升级为版本 2，并完成测试锁定。新评分器不再把来源标题或“尚未确认”区中的题目复述当作事实回答，不再把任意同义词猜测当作命中，也不再把路由、引用、状态和策略字段的变化混称为“结论不一致”。

本阶段没有改写第二套百题的原始报告，也没有把重评分结果用作修后验收。旧题已经属于开发集；重评分只用于证明新评分口径能识别原评分器的偏差。

## 评分契约变更

### 1. 受控语义表达

- 每个必需概念仍以冻结的 `anyOf` 字面候选为基础。
- 新增可选 `semanticAnyOf`：只有同一语义单元同时包含组内全部词项时才命中。
- 所有受控表达必须在题集首次运行前随题集一起封存，禁止看到回答后追加同义词。

### 2. 正文、缺口与来源分区

- “资料来源”中的文档标题不参与事实义务计分。
- 对可回答题，“尚未确认的部分”只用于证明缺口，不参与完整事实命中。
- 引用支持按回答语义单元核对，不能用答案末尾任意一个引用覆盖整篇回答的所有概念。

### 3. 安全策略的路由口径

- 对预期为拒绝或部分回答的请求，如果确定性入口策略在检索前完成安全拒绝，可接受零知识域、零引用。
- 仍要求作用域正确、策略状态为 `refused` 或 `needs_escalation`，并覆盖题集冻结的全部拒绝义务。
- 泛化的“不能”或固定 `not_covered` 文案不再自动算合理拒答。

### 4. 两类一致率分离

- 硬门 `three_output.conclusion_consistency` 只衡量可用性、事实/拒绝结论、必需概念和禁用主张是否一致。
- 另行报告 `operationalRate`，衡量状态、策略字段、路由、引用和完整度是否一致。
- 只有结论一致率进入原定企业硬门；运行态一致率作为稳定性诊断，不能冒充结论一致率。
