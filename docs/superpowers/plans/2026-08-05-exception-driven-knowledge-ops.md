# PSEAgent 异常驱动知识运营台实施计划

日期：2026-08-05  
对应设计：`docs/superpowers/specs/2026-08-05-exception-driven-knowledge-ops-design.md`

## 执行纪律

1. 每阶段先验证、后提交，提交标题和正文使用中文并包含“完成内容”“验证结果”。
2. 不暂存用户现有 `docs/local-runbook.md` 和 `.sisyphus/`。
3. 数据库/API 枚举保持英文；中文化只属于展示契约。
4. 问题、回答、聊天名和知识正文不进入问题组明文列、日志或审计元数据。
5. 非通过结论只创建人工待办和修订草稿；只有管理员确认且自动验证通过后才能写回和发布。
6. 修订草稿、验证详情中的问题和答案继续加密，作业载荷只传递记录 ID。
7. 单管理员可以完成修订和发布，但系统不得允许跳过验证直接关闭问题。

## 阶段 101：设计与运营边界

- 固化中文状态词典、行动导向总览、问题聚类、优先级、职责和隐私边界。
- 固化问题组生命周期、信息架构和规模化验收条件。

验证：设计与计划执行 `git diff --check`，无占位符。

## 阶段 102：中文状态与行动总览

- 建立穷尽中文状态词典，替换总览、反馈、复查、答案卡、作业、回归、发布和审计页面的裸英文状态。
- 总览展示严重错误、需人工复核、判断冲突、复查异常、自动通过和今日待办。
- 默认隐藏正常记录，提供中文筛选、状态说明和明确下一步动作。

验证：管理台单测、类型检查、构建及中文枚举静态检查。

## 阶段 103：问题中心数据闭环

- 新增 PostgreSQL 问题组与发生记录迁移、类型、Store、API、RBAC 和审计。
- Worker 将 `fail`、`needs_review` 和 `errored` 自动聚类；负面反馈形成或合并问题组。
- 同一来源幂等，统计发生次数、受影响人数、首次和最近发生时间。

验证：内存 Store、PostgreSQL、Service、Worker 聚类与隐私测试。

## 阶段 104：问题中心管理界面

- 新增待办中心和问题中心页面；按优先级和状态筛选，由当前后台管理员统一处理，不设置负责人或分派步骤。
- 问题详情关联反馈和复查元数据，支持分配、状态流转和审计。
- 总览改用服务端问题摘要，正常通过记录只进入统计。

验证：后台类型检查、构建、交互测试和 50+ 条记录分页/渲染检查。

## 阶段 105：全量质量与在线验收

- 执行 PostgreSQL 迁移并重启 API、Worker 和后台。
- 验证现有反馈/复查回填问题组，浏览器检查中文状态和行动队列。
- 执行全仓 TypeScript 测试、类型检查、构建、Rust 测试和工作树检查。

验证：在线健康、数据库计数、浏览器视觉证据和全量命令结果。

## 阶段 110：修订闭环设计

- 固化三层存储、根因路由、Agent 草稿、隔离验证、单管理员门禁和原子发布边界。
- 将问题状态改为由真实修订动作驱动，移除人工任意推进到已解决的能力。
- 固化修订工作台的信息架构、唯一主要操作、失败恢复和隐私要求。

验证：设计与计划执行 `git diff --check`，无占位符或未决策项。

## 阶段 111：修订数据与 API

- 新增修订草稿、验证运行和发布记录 PostgreSQL 迁移、类型、Store 与审计。
- 新增生成、保存、验证、发布、回滚 API；正文加密，列表只返回元数据。
- 由草稿和作业结果自动驱动问题状态；管理员仅可无需处理或重新打开。

验证：Schema、内存 Store、PostgreSQL、Service、API、权限、加密与状态机测试。

## 阶段 112：修订生成和根因路由

- 新增 `deepseek_v4_flash` 修订生成器，严格输出结构化草稿并进行确定性证据校验。
- Worker 按问题关联记录加载原问、原答、复查缺陷和正式证据，生成客户中立答案卡或知识补充建议。
- 无证据、逻辑问题和判断冲突不能伪装为可发布答案卡。

验证：模型契约、证据边界、客户信息去标识、五类用例和失败恢复测试。

## 阶段 113：隔离验证与安全写回

- 在 allowlist worktree 中渲染候选 Markdown，编译候选目录并运行五类定向回归和独立复查。
- 验证通过后允许单管理员发布，写回目标 Obsidian 仓库并生成可审计提交。
- 重新编译答案卡目录和知识索引，创建不可变快照并支持回滚。

验证：路径逃逸、基线漂移、Schema、定向回归、全量门禁、发布和回滚测试。

## 阶段 114：单管理员修订工作台

- 问题详情改为可深链完整页面，提供四步进度、证据区、结构化草稿编辑区和差异预览。
- 去掉问题状态下拉和常规 JSON/Git 输入，只保留当前唯一主要操作与无需处理。
- 增加自动保存、异步进度、失败原因、恢复按钮、键盘焦点和响应式布局。

验证：管理台单测、类型检查、构建、375/768/1024/1440 响应式和浏览器交互验收。

## 阶段 115：在线生效与端到端验收

- 执行 PostgreSQL 迁移，重启 API/Worker，问答服务接入活动目录热加载。
- 使用真实未通过问题完成生成、编辑、验证、发布、再次提问和自动复查全流程。
- 确认发布成功自动关闭、验证失败自动退回、活动版本可回滚且无正文泄露。

验证：服务健康、数据库记录、Git 提交、目录哈希、答案卡激活、正式回答复查、浏览器视觉证据和工作树检查。
